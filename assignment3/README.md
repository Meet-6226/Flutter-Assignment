# Flutter Profile Card

A simple Flutter application that demonstrates how to create a modern profile card screen using basic Flutter widgets and custom theme colors.

## About the Project

This project was created as a practical exercise to understand the basics of Flutter UI development. The screen contains a profile section with a profile icon, name, designation, statistics, and contact information.

The design uses a purple-based color theme with rounded containers, spacing, and simple shadows to create a clean and modern interface.

## Features

* Profile card UI
* Profile avatar using CircleAvatar
* Custom purple color theme
* Name and designation section
* Project, skills, and experience statistics
* Email and location information
* Icons for better visual representation
* Rounded corners and shadows
* Simple and responsive layout

## Getting Started

### Prerequisites

Make sure Flutter is installed on your computer.

You can check your Flutter installation using:

```bash
flutter doctor
```

### Run the Project

Clone the repository:

```bash
git clone <your-repository-link>
```

Go to the project folder:

```bash
cd profile_card
```

Install the required dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
