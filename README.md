Responsive Dashboard

Project Overview

This project is a responsive multi-section dashboard built using Flutter. The dashboard provides a simple and clean interface with a left sidebar, summary cards, quick access options, and a recent activities section.

Main Features

* Responsive Layout: The dashboard adjusts its layout based on the available screen size.
* Sidebar Navigation: A simple left-side navigation menu provides access to different sections such as Home, Profile, Messages, Reports, and Settings.
* Summary Cards: Displays basic information such as total users, orders, and tasks.
* Quick Access: Provides clickable cards for commonly used sections.
* Recent Activities: Shows recent actions in a scrollable list.
* Interactive Navigation: Dashboard cards and sidebar options can be clicked to open their respective pages.

Flutter Concepts Used

* ListView – Used for the scrollable dashboard and activity section.
* GridView – Used to arrange the Quick Access options.
* MediaQuery – Used to detect the screen width and adjust the layout.
* Expanded – Used to distribute available space between dashboard cards.
* Flexible – Used to prevent content from overflowing inside cards.
* Row & Column – Used to structure and align different sections of the dashboard.
* InkWell – Used to make dashboard cards interactive.
* Navigator – Used for moving between dashboard and detail pages.

Objective

The main objective of this project is to understand how Flutter’s layout widgets can be combined to create a responsive and interactive dashboard that remains properly aligned across different screen sizes.
