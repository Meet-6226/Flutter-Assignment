# Flutter Assignments

A collection of Flutter projects and exercises covering core Dart concepts, UI design, state management, navigation, REST APIs, and local data caching.

---

## 📂 Repository Structure

| Directory | Title | Description |
| :--- | :--- | :--- |
| **`assignment1`** | **Food Delivery Dashboard** | Multi-page food app with sidebar navigation, order tracking, offers, and custom widgets. |
| **`assignment2`** | **Dart Async & Models** | Core Dart fundamentals, asynchronous programming (`Future`, `async`/`await`), and null safety. |
| **`assignment3`** | **Profile Screen UI** | Clean and modern user profile user interface. |
| **`assignment4`** | **Responsive Dashboard** | Responsive dashboard layout adapting across different screen sizes. |
| **`assignment5`** | **Todo Application** | Interactive Todo list app with task creation, toggle completion, and deletion. |
| **`assignment6`** | **Dynamic Product Catalog** | Product listing with interactive modal bottom sheets and custom product cards. |
| **`assignment7`** | **Navigation & Form Validation** | Multi-screen app (Home, Register, Profile) with form validation and route arguments. |
| **`assignment8`** | **REST API & Local Caching** | Fetches live posts from JSONPlaceholder API using `http` and caches data offline using `shared_preferences`. |

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.13.0 or later)
- Dart SDK
- Android Studio / Xcode / Chrome (for web)

### Running Any Assignment

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Meet-6226/Flutter-Assignment.git
   cd Flutter-Assignment
   ```

2. **Navigate to the desired assignment folder:**
   ```bash
   cd assignment8
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the application:**
   ```bash
   flutter run
   ```
